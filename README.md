# Full-Scale-E-Commerce-Revenue-Product-Performance-Monitoring-Dashboard
Excel interactive Dashboard | Mohammed Sufiyan
	
	🔍 Project Overview
This project is an Excel dashboard I created to explore and understand e-commerce sales data.
The goal was to turn raw data into something visual and easy to interpret.
The dashboard highlights sales performance, customer patterns, and delivery behavior through a set of charts and KPIs.

	🎯 What the Dashboard Covers:
Top-selling products
Revenue and quantity trends over time
Customer purchase preferences
Location-wise order distribution
Delivery time analysis
Key business metrics in one place

	🧠 Insights from the Data:
Here are some of the insights the dashboard helps reveal:
Which products are ordered the most
States with the highest customer activity
Weekly sales and quantity patterns
Differences in buying behavior across channels and genders
Quick overview of orders, units sold, ratings, and delivery days

	🛠 Tools & Techniques Used:
Microsoft Excel
Pivot Tables & Pivot Charts
Slicers for filtering
Conditional formatting for KPIs
Data cleaning and formatting
Basic UI design for dashboard layout

	🚀 How to Use the Dashboard
Download the Excel file
Open and enable editing
Use the slicers to filter data by:
Gender Mode
Product Mode
Explore the charts and KPIs to understand the insights

	🧾 About the Dataset
The dataset used for this project is a synthetic sample created for learning and practice.
It includes a little over 1,000 transactions with basic customer and product details.
